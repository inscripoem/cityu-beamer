The logos are embedded in the original raster backgrounds; the theme does not use separate SVG logos. These PNGs have not been traced, recoloured, or regenerated. Presentation text, mathematics, tables, and diagrams are typeset separately in LaTeX. TeX Gyre Heros substitutes for the PPT's Arial, so this is not a claim of pixel-identical text layout. The source PPT is not included in the repository or import ZIP.
